# Feature Matrix - Farm Direct AI Prototype

| Feature | Status | Evidence/File | Notes |
|---|---|---|---|
| **Authentication** | 🟡 PARTIAL | DemoContext with localStorage role persistence; role toggle farmer/consumer; no real backend auth | Login/signup screens not implemented; all "auth" is client-side demo state |
| **Farmer registration** | 🟠 MOCKED | Hardcoded farmer IDs (f-001 through f-015) in mockData.ts; AddProduceForm uses mock farmers | No dynamic registration; f-001 is default current farmer |
| **Buyer registration** | 🟠 MOCKED | Hardcoded buyer IDs (b-001 through b-010) in mockData.ts; no signup flow | All buyer data is static mock data |
| **Farmer listing** | 🟡 PARTIAL | AddProduceForm component + farmerInventoryService.addProduce() → POST /api/produce; mock data persistence | Backend API exists; uses mock farmers; localStorage fallback |
| **Buyer requirement** | 🟡 PARTIAL | mockBuyerRequirements in mockData.ts + /api/buyer-requirements endpoint; voice intent creates requirements | All data mocked; no real requirement creation |
| **Voice input** | 🟡 PARTIAL | Browser SpeechRecognition in VoiceAssistant/FarmDirectAssistantWidget; onParsedResult callbacks | STT works natively in browser; AI backend needs API key |
| **Speech-to-text** | 🟡 PARTIAL | window.SpeechRecognition / window.webkitSpeechRecognition implemented | Native browser API only; no external STT provider |
| **AI extraction** | 🟡 PARTIAL | parseVoiceIntent() in aiService.ts → /api/voice-intent + local fallback; validateAiVoiceIntent() | Backend OpenRouter AI requires API key; local fallback works without it |
| **Multilingual support** | 🟡 PARTIAL | Hindi + English + Hinglish in prompts, parsing, UI; product aliases with Hindi names (tamatar, aloo); Language = 'en' | Language toggle in DemoContext; detectLanguage/detectResponseLanguage functions |
| **Matching** | 🟡 PARTIAL | matchFarmers() + matchBuyers() in aiService.ts - rule-based weighted scoring | Availability(30%)+Price(25%)+Distance(20%)+Quality(15%)+Reliability(10%); NOT AI-based |
| **Price discovery** | 🟡 PARTIAL | getPricing() in productService - selling/market/reference mandi prices + discount %; ~24% savings display | Formulaic price calculation; not AI-driven price optimization |
| **Multiple-farmer aggregation** | 🟡 PARTIAL | aggregateSupply() - greedy allocation across farmers; isFulfilled flag; remainingKg tracking | Partial fulfilment supported; if total farmer supply < requested, remaining stays open |
| **Orders** | 🟡 PARTIAL | OrderStatus type + all statuses (negotiating/confirmed/stored/dispatched/in_transit/delivered/cancelled); createOrder() in mockData; activeOrder in DemoContext | All order data mocked; no real order creation or management API |
| **Notifications** | 🟠 MOCKED | UI hints only in some components (BuyerCard contact, OrderTimeline); no websockets/push/email | No real notification system |
| **FPO integration** | 🟠 MOCKED | FPO data in mockData.mockFPOs; FPO member flag on farmers; FPO name displayed in UI | No FPO backend integration, no aggregation logic, no transaction logic |
| **Storage** | 🟡 PARTIAL | mockStorageUnits in mockData; StorageCard component with facility type, temp, RH, solar, IoT; allocation UI | All storage mocked; UI selection only; no backend booking API |
| **Cold storage** | 🟠 MOCKED | Cold storage unit types (Solar Micro-Cold Room, Cooperative CA Storage, Hermetic Silo, Standard Cold Hub); UI allocation | No cold storage integration; allocation is UI-only state change |
| **Transport** | 🟠 MOCKED | mockLogisticsVehicles in mockData; VehicleCard component with type, capacity, driver, ETA, cold chain; logistics allocation | All logistics mocked; vehicle assignment is UI selection; no dispatch API |
| **GPS** | 🟠 MOCKED | Route simulation in UI (RouteCard with waypoints, stops); estimatedTransitTime display | No real GPS tracking; all route data is hardcoded mock data |
| **Delivery tracking** | 🟡 PARTIAL | ConsumerTrackingPage with simulated live map; OrderTimeline; RouteCard with waypoint details | Simulated tracking; no real GPS, temperature telemetry is mock data |
| **Database** | 🟠 MOCKED | JSON files (mockData.ts) + localStorage for farmer inventory + produce-store.json; no real DB | CRUD via mock data + localStorage; fetch endpoints in server/aiIntentApi.mjs return mock data |
| **External APIs** | 🟡 PARTIAL | OpenRouter AI API (defaults to gpt-4o-mini); Browser SpeechRecognition/SpeechSynthesis | OpenRouter requires AI_API_KEY env var; falls back to local parsing; speech uses native browser APIs |
| **API: /api/produce** | 🟡 PARTIAL | GET/POST/PUT/DELETE in server/aiIntentApi.mjs; merges mock + stored produce | Backend API functional; uses produce-store.json + extraProduce for persistence |
| **API: /api/buyer-requirements** | 🟡 PARTIAL | GET in server/aiIntentApi.mjs; returns serverMockBuyerRequirements + query filtering | All data mocked; basic query filtering implemented |
| **API: /api/marketplace/search** | 🟡 PARTIAL | POST in server/aiIntentApi.mjs; unified buyer search with product/price/location/grade filters | Real marketplace search; uses mock data + localStorage inventory; query params work |
| **API: /api/voice-intent** | 🟡 PARTIAL | POST in server/aiIntentApi.mjs; OpenRouter AI extraction with fallback to local parseVoiceIntentFallback | Requires AI_API_KEY; fallback local parsing works without key; returns structured ParsedVoiceIntent JSON |
| **API: /api/assistant-response** | 🟡 PARTIAL | POST in server/aiIntentApi.mjs; OpenRouter natural language response with context | Requires AI_API_KEY; fallback assistantResponseFallback() works without key; generates Hindi/English responses |
| **AI: matchFarmers** | 🟡 PARTIAL | matchFarmers() in aiService.ts - rule-based; filters mockProduceListings by product match; scores by availability/price/distance/quality/reliability | Uses mock data only; no real farmer database |
| **AI: matchBuyers** | 🟡 PARTIAL | matchBuyers() in aiService.ts - rule-based; filters mockBuyerRequirements by product match; scores by availability/price/distance/quality/reliability | Uses mock data only; no real buyer database |
| **AI: aggregateSupply** | 🟡 PARTIAL | aggregateSupply() in aiService.ts - greedy allocation across farmers; fulfilledKg/remainingKg tracking; isFulfilled flag | Partial fulfilment supported; explanation text generated |
| **AI: suggestNegotiation** | 🟡 PARTIAL | suggestNegotiation() in aiService.ts - calculates suggested price; reasoning array; confidence score | Formulaic; buyerOffer + gap*0.67; no real negotiation state |
| **AI: optimizeRoute** | 🟡 PARTIAL | optimizeRoute() in aiService.ts - 3 hardcoded route options (A/B/C) with distance/cost/duration | 3 hardcoded routes; no real routing API; recommendedRoute = route C |
| **Farmer dashboard** | 🟡 PARTIAL | FarmerDashboardPage with 7 tabs (my-produce/add-produce/inventory/buyer-requests/orders/earnings/demand); farmerInventoryService | All data from mockData + localStorage; AI matching via matchBuyers() |
| **Consumer dashboard** | 🟡 PARTIAL | ConsumerDashboardPage with voice CTA + text typing; recent requests from mockOrders; language toggle | Voice routes to ConsumerVoicePage; text typing routes to same page; all data mocked |
| **Farmer voice page** | 🟡 PARTIAL | FarmerVoicePage with VoiceAssistant mode=farmer; onParsedResult → matchBuyers(); capability cards | Voice intent parsing + buyer matching; TTS for responses; no actual microphone access in audit |
| **Consumer voice page** | 🟡 PARTIAL | ConsumerVoicePage with VoiceAssistant mode=consumer; onParsedResult → handleFindFarmers → navigate('/consumer/matches'); isFinding state | Voice intent → farmer matching; navigation to matches; finding state management |
| **Order page (farmer)** | 🟡 PARTIAL | FarmerOrderPage with activeOrder from DemoContext; Payout summary; OrderTimeline; impact metrics | All order data from mock/default activeOrder; impact calculations are formulaic |
| **Order page (consumer)** | 🟡 PARTIAL | ConsumerOrderPage with contract breakdown; price comparison (mandi vs direct); storage + logistics navigation | ActiveOrder from DemoContext; mandi/retail benchmark comparison; all mocked |
| **Storage page** | 🟡 PARTIAL | ConsumerStoragePage with mockStorageUnits grid; StorageCard; onSelect → updateActiveOrder + navigate('/consumer/logistics') | UI allocation only; no backend storage booking; selected unit stored in activeOrder |
| **Logistics page** | 🟡 PARTIAL | ConsumerLogisticsPage with mockLogisticsVehicles grid; VehicleCard; handleSelectVehicle → updateActiveOrder + navigate('/consumer/tracking') | UI vehicle selection only; no real logistics dispatch; all vehicles from mock data |
| **Tracking page** | 🟡 PARTIAL | ConsumerTrackingPage with live map simulation; RouteCard; OrderTimeline; temperature telemetry display | Simulated tracking; GPS coordinates are mock; temperature readings are static |
| **Impact page** | 🟡 PARTIAL | ConsumerImpactPage with comparison chart (Traditional Mandi vs FarmDirect AI); farmer earnings %; consumer discount %; environmental impact | All metrics from activeOrder.impact; formulaic calculations; no real impact data |
| **Call page** | 🟠 MOCKED | ConsumerCallPage with simulated call status progression (connecting→active→negotiated over timers); AI mediation display | Timed timer-based status flow; no real call integration; AI mediation text is hardcoded |
| **Home page** | 🟡 PARTIAL | HomePage with hero section + buyer marketplace (filtered product grid) + seller hub; farmer features cards | buyerProducts from productService; inventoryVersion for real-time updates; all data from mockData |
| **Topbar/BottomNav/Layout** | 🟡 PARTIAL | Layout with Outlet + Sidebar + Topbar + BottomNav + FarmDirectAssistantWidget; role-based routing | Router-driven page flow; assistant widget stateful with intro/chat views |
| **Product Details** | 🟠 MOCKED | ProductDetailsPage at /product/:id (referenced but not fully inspected); ProductDetailsModal in HomePage | Referenced in HomePage.handleViewProduct; navigation exists but component not fully audited |
| **BuyerCard** | 🟡 PARTIAL | BuyerCard component with buyer info + demand + type + connect button | Uses mockBuyer data; connect navigates to /farmer/connection or /consumer/call |
| **OrderTimeline** | 🟡 PARTIAL | OrderTimeline component with timeline items; status icons (completed/in_progress/pending); step descriptions | Uses activeOrder.timeline from DemoContext; mock timeline data |
